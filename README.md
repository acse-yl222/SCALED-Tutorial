## SCALED Tutorial (WP4)

This repository hosts the hands-on material for the WP4 segment of the **SCALED Tutorial**, where we practice building scalable, learning-enabled digital twins for physics-based systems. The codebase is intentionally lightweight: each lesson exposes a single Python entry point that you can expand with your own models, data loading logic, and evaluation pipelines.

### Learning Path

| Lesson | Folder | Focus |
| --- | --- | --- |
| L1 | [l1_regression_based_surrogate_model](l1_regression_based_surrogate_model/) | Regression-based surrogate model (compression + inference) |
| L2 | [l2_diffusion_based_surrogate_model](l2_diffusion_based_surrogate_model/) | Diffusion-based surrogate model (DDPM / DDIM) |
| L3 | [l3_inference_model_trainning](l3_inference_model_trainning/) | Training the latent compression + inference model |
| L4 | [l4_domain_decomposition_method](l4_domain_decomposition_method/) | Domain decomposition for large-scale inference |
| L5 | [l5_boundary_condition_setting](l5_boundary_condition_setting/) | Boundary condition setting (validated with NN4PDEs) |

### Getting Started

1. **Clone** the repository and move into the project root.
   ```bash
   git clone https://github.com/acse-yl222/SCALED-Tutorial.git
   cd SCALED-Tutorial
   ```
2. **Create a Python environment** (3.10+ recommended).
   ```bash
   conda create -n scaled python=3.10
   pip install torch torchvision torchaudio
   pip install -r requirements.txt
   pip install -e .
   ```

## Producing data for the SCALED model (geometry + NN4PDEs + pollution model)

The SCALED surrogate is trained and evaluated on data generated by a classical physics pipeline. You only need this step if you want to (re)generate the training/inference dataset rather than use a released one. The pipeline goes:

```
Building geometry  ──►  NN4PDEs (CFD solver)  ──►  airflow field (u, v, w)  ──►  Pollution model (upwind)  ──►  pollutant concentration C
   (geometry link)        tools/NN4PDEs.py           data/.../*.h5                tools/pollution_code.py        data/.../_conservation/*.h5
                                                                                          │
                                                                                          ▼
                                                       SCALED model: train (L3) and inference (L1 / L2 / L4)
```

1. **Geometry → airflow with NN4PDEs.** [tools/NN4PDEs.py](tools/NN4PDEs.py) (and [tools/NN4PDEs_big.py](tools/NN4PDEs_big.py) for the larger domain) loads the downloaded building geometry (`data/geometry/INHALE_1280.npy`), converts it into the solid mask `sigma`, and runs the CFD solver to produce the time-resolved velocity field `(u, v, w)`. The results are written as per-timestep HDF5 files (`uvw`) under `data/SCALED_dataset/south_kensington/`, together with `sigma.npy`.

2. **Airflow → pollutant concentration with the pollution model.** [tools/pollution_code.py](tools/pollution_code.py) implements a conservative 3D **upwind** scheme that transports a pollutant source through the city using the NN4PDEs airflow `(u, v, w)` and the same building geometry (`sigma`) for blocking. It reads the `uvw` HDF5 files and writes the concentration field `C` to `data/SCALED_dataset/south_kensington_conservation/`.

3. **SCALED model: train & inference.** The generated `(u, v, w)` and `C` fields are the dataset for the SCALED surrogate:
   - **Train** the compression + inference model in [l3_inference_model_trainning/tutorial.py](l3_inference_model_trainning/tutorial.py) (reads `data/SCALED_dataset/south_kensington`).
   - **Run inference** with the released weights in L1/L2/L4 — the geometry is fed to the model as a control/condition input, so the same downloaded geometry is used at both data-generation and inference time.

> In short: use **geometry + NN4PDEs** to generate the airflow, use the **upwind pollution model** to spread the pollutant through the city on top of that airflow, and feed the resulting fields to the SCALED model for training and inference.
